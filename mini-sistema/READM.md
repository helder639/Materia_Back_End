# API de Gerenciamento de Pessoas (Node.js + Express + Sequelize + PostgreSQL)

API desenvolvida em Node.js utilizando Express, Sequelize e PostgreSQL para o gerenciamento de registros de pessoas com suporte a filtros, ordenação e paginação.

---

## 🛠️ Tecnologias Utilizadas
- **Node.js**
- **Express**
- **Sequelize** (ORM)
- **PostgreSQL**

---

## 📋 Pré-requisitos
Certifique-se de ter instalado em sua máquina:
- [Node.js](https://nodejs.org/)
- [PostgreSQL](https://www.postgresql.org/)

---

## 🚀 Como Executar o Projeto

1. **Clone o repositório ou abra a pasta do projeto:**
   ```bash
   cd mini-sistema

2. **Instale as dependencias**
   ```bash
   npm install

3. **Configure o Banco de Dados:**
   Crie um banco de dados no PostgreSQL chamado api_pessoas
   Verifique suas credenciais de acesso no arquivo de configuração (config/db.js).

4. **Inicie a aplicação:**
   ```bash
   node app.js
